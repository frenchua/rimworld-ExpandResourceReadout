This is a small mod for RimWorld that remembers the resource readout's (the list of resources in the upper left corner of the screen) expand/collapse state between game loads (assuming the resource readout is sorted by categories), either globally across all saves or per save file - configurable in the mod's settings. It also adds a right-click menu to expand or contract the readout.

# Installing the mod
Clone the repository into the `Mods` directory of your RimWorld install and run `dotnet build` and you should be good to go.
